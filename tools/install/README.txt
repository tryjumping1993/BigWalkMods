BIG CHRISTMAS WALK  (version: see version.txt)
================================================

A winter island for Big Walk: puzzles, a railway, a mine, skiing, planes, and more. It is a mod, so everyone you walk
with needs it installed, at the same version.

You need: Big Walk on Steam, on Windows, and about 2 GB of free disk space.

INSTALL
  1. Close Big Walk.
  2. Unzip this whole download somewhere (right-click the zip > Extract All). Do not run it from inside the zip.
  3. Double-click Install.cmd. It finds Big Walk through Steam and copies the mod into the game's folder.
     If Windows SmartScreen warns about it: More info > Run anyway.
  4. Start Big Walk from Steam as usual. The FIRST start takes a few minutes and needs the internet (the mod loader
     prepares itself; a black console window may flash). Later starts are quick.
  The island lies off the coast near the start of the walk; follow the causeway.

UPDATE
  Download the new version and run its Install.cmd. It replaces the old one (no need to uninstall first).

UNINSTALL
  Double-click Uninstall.cmd. It removes exactly what Install.cmd added and puts back anything it replaced.
  (Steam's "Verify integrity of game files" does NOT remove mods: use Uninstall.cmd.)

NOTES
  - With the mod installed, Big Walk always starts with it. Your saves are not changed, but a walk on the island is
    best kept on its own save slot.
  - Everyone in a walk must have the same version, or the island's puzzles will not match up.
  - Problems? The mod loader's log is BepInEx\LogOutput.log in the game's folder: send it along.

Built on BepInEx and the Big Puzzle SDK by markviews, with other open-source parts: see THIRD-PARTY-NOTICES.txt and
