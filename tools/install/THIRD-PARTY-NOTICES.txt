BIG CHRISTMAS WALK: THIRD-PARTY NOTICES
=======================================

Big Christmas Walk is an unofficial fan mod for Big Walk (House House). It contains none of the game's own files: it
uses the game's assets only at run time, from your own copy of the game.

The download ships these open-source components unmodified. Each one's licence text is in the licenses folder beside
this file. The LGPL components are unmodified builds; their source is at the addresses given, and you may replace them
with your own builds (they are ordinary files in the game folder after installing).
